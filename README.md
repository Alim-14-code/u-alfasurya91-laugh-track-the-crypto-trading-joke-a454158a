# Laugh Track: The Crypto Trading Joke Contest

One line, under 200 characters, about crypto and trading life.

## Entry

> I checked the chart eight times today for a coin I swore I'd hold for five years — it's been three days.

104 characters. The setup promises a five-year hold; the punchline is that it's been three days and the chart has already been checked eight times.

## Run

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
